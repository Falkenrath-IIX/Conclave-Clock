# Conclave-clock

Custom minimal clock skins for Rainmeter. This repository contains both Dark and Light variants with a smooth fade gradient effect on the date and a clean vertical day display.

## ✨ Features
- Dual Variants: Includes both Dark and Light themes to match any desktop wallpaper.
- Fade Gradient Effect: Large date numbers smoothly fade out towards the bottom.
- Vertical Day Display: Unique and clean vertical lettering for the current day.
- Scale Supported: Easily resizable via the Scale variable in the code.

## 🛠️ Installation
1. Download or clone this repository.
2. Move the skin folders (Dark Clock Conclave and Light Clock Conclave) to your Rainmeter skins directory (usually C:\Users\YourName\Documents\Rainmeter\Skins).
3. Open Rainmeter, find the skins, and click Refresh all.
4. Load the .ini file from your preferred theme.
